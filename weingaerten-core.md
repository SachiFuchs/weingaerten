# Weingärten core – house model (catalog, walls, layers, openings, materials)

> **This is a non-code program.** This prompt *is* the program: the agent reads it and does the work with its tools.
> This file contains **no source code** and **no model data** – only the description and the instructions for creating the code.
> Code is allowed **only** for the items in the **Exception list**. The agent generates that code from the
> specification, stores it in the **code folder** (`code\` of the project), and reuses it – it is never written into this prompt.

## Documentation

| | |
|---|---|
| **Purpose** | The model of the house: catalog of reusable types (materials, assemblies, component classes, components) and the concrete house (foundation, storeys, walls with openings, rooms). No visualisation. |
| **Data** | Outside this prompt, one JSON file per element: `catalog\<folder>\<id>.json` (types) and `house\house.json` + `house\storeys\<id>.json` (instances). Schemas in `catalog\schema\` (enforced by `VALIDATE` and before every write). |
| **Naming** | Keys, ids, folder names, enums and commands in English; human-readable values (`name`, `description`, `category`) in German. Ids kebab-case `^[a-z0-9]+(-[a-z0-9]+)*$`. |
| **References** | `"<type>:<id>"` – `material:`, `assembly:`, `class:`, `component:`, `company:`, `document:`, `storey:`. Chains: wall → assembly → layers → material; wall → openings → component → class, component → materials (by role); component → product → manufacturer / suppliers (companies); opening → reveal material. |
| **Interface** | One function `handle(command_json: str) -> str` – JSON command in, JSON answer out. No HTTP, no pages. |
| **Used by** | `weingaerten-web.md` imports the generated package. |
| **Tools** | Shell (PowerShell), file `write`, Python 3 (standard library only). |
| **Limitations** | Editable: catalog elements (`SAVE`, `DELETE`), the openings of a wall (`OPENING_SAVE`, `OPENING_DELETE`), the interior linings of a wall (`LINING_SAVE`, `LINING_DELETE`), and walls, rooms and the storey height (`WALLS_SAVE`), a room with its coverings (`ROOM_SAVE`, `ROOM_DELETE`) and the shafts of the house (`SHAFT_SAVE`, `SHAFT_DELETE`) and the installed parts (`PART_SAVE`, `PART_DELETE`); the foundation follows the outline. Walls and rooms are axis-parallel (90° grid); furniture is prepared in the schema but not computed. |

## Hard rules
- Code files may be written only in the code folder. Never write code or model data into this prompt.
- Never write hash files into the project root. The code hash lives in `.hash\` in the code folder; any hash file kept in the project goes to `hashes\` next to this prompt.
- At runtime the module reads `WEINGAERTEN_HOME\catalog\**\*.json` and `WEINGAERTEN_HOME\house\**\*.json`. It **writes or deletes only** `WEINGAERTEN_HOME\catalog\<materials|assemblies|classes|components|companies|tga-classes|tga-components>\<id>.json` (through `SAVE` / `DELETE`) and `WEINGAERTEN_HOME\house\storeys\<id>.json` (through `OPENING_SAVE` / `OPENING_DELETE` – only the `openings` of one wall –, `LINING_SAVE` / `LINING_DELETE` – only the `linings` of one wall –, `ROOM_SAVE` / `ROOM_DELETE` – one room with its coverings – and `WALLS_SAVE` – walls, rooms, `height`) and `WEINGAERTEN_HOME\house\house.json` only through `SHAFT_SAVE` / `SHAFT_DELETE` (only its `shafts`) and `WEINGAERTEN_HOME\house\tga\parts\<id>.json` only through `PART_SAVE` / `PART_DELETE`. Never schemas. It starts no servers and uses no network. If `WEINGAERTEN_HOME` is not set, every command except `VALIDATE` answers `{"error": "WEINGAERTEN_HOME nicht gesetzt"}` and `VALIDATE` reports it as an error.
- Data is (re)loaded on every command when any file's modification time or the set of files changed; otherwise the cached load is used. The import inbox folders `catalog/imported_*` (raw shop imports, not part of the model) are not scanned.

## Core specification
Exception #1. Python 3 package `weingaerten_core`, standard library only, structured as in **Code structure** (end of this section). Entry point `handle(command_json: str) -> str`, importable as `import weingaerten_core` with the `code` folder on `sys.path`. Thread-safe (one lock around loading and writing). Floats in answers rounded to 4 decimals.

**Commands** – request `{"command": <name>, ...}`; answer JSON; errors → `{"error": <text>}` (invalid JSON, unknown command, missing argument).
| Command | Answer |
|---|---|
| `CATALOG` | request `{type?, full?}` → `{elements: [{ref, type, id, name, category}]}` – sorted by type (material, assembly, class, component, company, document), then id; `category` = material/assembly category, the class ref for components, the geometry for classes, the roles joined with `, ` for companies; with `full: true` each entry is the `ELEMENT` answer instead (the web loads all elements with one call) |
| `ELEMENT` | request `{ref}` → raw JSON plus `{ref, type, file}`; unknown → `unbekannt: <ref>` |
| `RESOLVE` | request `{ref}` → element with every reference replaced by the resolved element (recursive, keeps `ref`; a reference to an element that is already being resolved on the current path – a cycle such as material → offer document → item material – stays the ref string); assemblies also `thickness` and layer `offset` |
| `HOUSE` | computed house (see **Answer of HOUSE**) |
| `VALIDATE` | `{ok, errors, warnings, counts}` |
| `BOM` | quantities (see **BOM**) |
| `USAGE` | request `{ref}` → `{ref, used_by}` – every catalog ref, `house` or `storey:<id>.<wall id>` that references it (anywhere in its JSON), sorted; request `{all: true}` → `{usage: {<ref>: [users]}}` for every catalog element, computed in one pass |
| `SAVE` | request `{ref, element, create}` → `{ref, element, file, warnings}` (catalog, see **Editing**; also `tga-class:` / `tga-component:`, checked with their schema and the connection rules) |
| `TGA_CATALOG` | `{elements: {<ref>: element + {ref, type}}, conductors: {<ref>: [{role, color}]} (cables), issues: [{where, message, level}], abstracts: {<ref>: abstract of TgaTree} (deprecated), assemblies: {<ref>: TgaAssembly.summary}, trees, placement: {<ref>: {hosts, modes, derived, none}}}` (tga-trees included in elements) – every tga-class and tga-component with the connection issues of the catalog |
| `DELETE` | request `{ref}` → `{ref, deleted: true}` |
| `OPENING_SAVE` | request `{storey, wall, opening, create}` → `{storey, wall, opening, warnings}` (see **Editing openings**) |

**Data loading**
- Catalog folders → type: `materials` → `material`, `assemblies` → `assembly`, `classes` → `class`, `components` → `component`, `companies` → `company`, `documents` → `document`. `catalog\schema\` is ignored; other folders are ignored; non-`.json` files are ignored.
- Each file holds one element; its `id` equals the file name. House: `house\house.json`; each `storey:<id>` → `house\storeys\<id>.json`. Invalid JSON → error `kein gültiges JSON`, file skipped.

**Units and coordinates**
- Metres. Plan: origin top-left, `x` right, `y` down; `z` up. Foundation top `z = foundation.top` (= 0). Storey walls from `z0 = elevation` to `z1 = z0 + height` (`height` = the wall's optional own `height`, e.g. a knee wall / Kniestock, else the storey height; a wall `height` ≤ 0, not a number or above the storey height → error `Wandhöhe ungültig`, the storey height is used). Layer pieces and face areas use the wall height. **Roof** (`storey.roof` `{kind: "gable", pitch, knee_wall_height, ridge_direction: south_north|west_east (default south_north), eaves: [c0, c1]}`; pitch in (0, 90), knee > 0, c0 < c1, else error `Dach ungültig` at `<storey>.roof`): roof underside height above the storey floor at a plan point `h = knee + tan(pitch) · max(0, min(c − c0, c1 − c))` with `c` = x (south_north) or y (west_east), ridge at `(c0 + c1)/2`, `ridge_height = knee + tan(pitch)·(c1 − c0)/2`. A wall with `shape.kind: roof` takes its top `z_top(u) = h(point of the reference line at u)` (walls parallel to the ridge are level, walls across it are gables); without `storey.roof` → error `Dach fehlt für Dachwand` (wall stays rectangular). Its `height` = highest top over the outside u range (may exceed the storey height); the ridge u is an extra slab break of the layer pieces; a piece under a sloped top gets `top_plane` `[a, b, c]` (absolute `z = a·x + b·y + c`), `z1` = its highest corner and volume = area × (plane at the slab centroid − z0); other pieces `top_plane: null`. Face and room segment areas = area under the top line minus holes; openings need `zt ≤` the lowest top over `[u0, u1]`. Wall output adds `profile` `[[u, z]]` (top line over the outside u range with the ridge kink); storey output `roof` = `{kind, pitch, knee_wall_height, ridge_direction, eaves, ridge, ridge_height}` or null. Angles in degrees, 0 = +x, clockwise.
- Line start → end with direction `d`: **left normal** `(dy, −dx)`, **right normal** `(−dy, dx)`.

**Layers**
- `layer_order` by `category`: `exterior_wall` → `outside_in`, `interior_wall` → `left_right`, `base_slab` / `slab` / `roof` / `plinth` → `top_down`, `interior_lining` / `covering` → `wall_out`; otherwise error.
- `thickness` = sum of layer thicknesses; layer `i` occupies `[offset_i, offset_i + thickness_i]` from the first face.

**Classes** (`class`)
- `geometry` = drawing recipe: `window`, `door`, `box`. Required parameters of the recipe (key and type): `window` → `width`, `height`, `depth`, `frame_width` (length) and `sashes` (choice with options ⊆ {0, 1, 2, 3}: number of panes, each with one sash; 0 = one fixed pane) and optionally `opening_1` … `opening_3` (choice ⊆ {`fixed`, `turn_left`, `turn_right`, `tilt`, `tilt_turn_left`, `tilt_turn_right`, `pivot`}; opening type of pane 1–3 counted from the left seen from inside, `left`/`right` = hinge side; default when missing: 1 pane `tilt_turn_left`, otherwise first pane `tilt_turn_left`, last pane `tilt_turn_right`, middle panes `tilt_turn_left`; `fixed` = pane without sash; `pivot` = horizontal pivot (Schwingflügel, roof window)); `door` → `width`, `height`, `depth`, `frame_width` (length) and optionally `swing` (choice `left`/`right`); `box` → `width`, `height`, `depth`; `passage` (Durchgang, wall opening without frame and leaf) → `width`, `height` (length). Missing → error `Rezept <geometry> braucht Parameter <key>`.
- Parameter rules: keys unique; `choice` needs non-empty `options`; `default` (if given) must be valid for the parameter (type, min/max, options); `min` ≤ `max`. Material roles: keys unique; `default` must resolve to a material.

**Components** (`component`)
- `class` resolves to a class. `params` must contain every `required` parameter of the class and no unknown key (`unbekannter Parameter <key>`); values: `length`/`number` numbers within `min`/`max`, `choice` one of `options`, `bool` boolean. `materials` must contain every role of the class (`Materialrolle <key> fehlt`) with a resolving material and no unknown role.
- `opening_capable` may differ from the class default.
- Optional `product` (the component as a finished product; materials may carry the same block, plus `ean`, `url` and `details`, and are checked with the same rules; `details` = optional shop tables `{product_data: [{label, value}], dimensions_weight: [{label, value}]}` – English keys, label/value strings in the shop's wording, not validated beyond the schema): `manufacturer` must resolve to a company with role `manufacturer` (`Firma ist kein Hersteller: <ref>`); every `offers[].supplier` must resolve to a company with role `supplier` (`Firma ist kein Lieferant: <ref>`); `price` ≥ 0; `currency` default `EUR`; `price_basis` optional (`net` | `gross`, missing = not stated).

**Companies** (`company`) – `roles` non-empty subset of `manufacturer`, `supplier`, no duplicates.

**Documents** (`document`, folder `catalog\documents\`, read-only: `SAVE` / `DELETE` answer `ungültige Referenz`; written only by `scripts\import_documents.py`) – invoices, quotes, order confirmations, credit notes and plans (no prices, `items` empty) `{id, name, doc_type invoice|quote|order_confirmation|credit_note|plan, supplier, date, number?, customer_number?, category?, object?, project?, description?, prices_are_net?, items_gross?, items: [{position?, description, quantity?, unit?, unit_raw?, unit_price?, total_price?, ref?}], subtotal_net?, discount_net?, shipping_net?, deductions_net?, total_net?, vat_rate?, vat_amount?, total_gross?, currency, related?: [document refs], pdf?, imported_from?, source_sha256?, original_filename?}`. `supplier` must resolve to a company with role `supplier` (`supplier: unbekannt: …` / `Firma ist kein Lieferant: …`); `items[].ref` (`material:`, `component:` or `tga-component:` – the latter looked up in `model["tga"]["elements"]`) and `related[]` must exist (`unbekannt: …`). Sums are warnings `Belegsumme weicht ab: …` (tolerance 0.05): item totals (divided by `1 + vat_rate/100` when `items_gross`) vs `subtotal_net`; `subtotal_net − discount_net + shipping_net − deductions_net` vs `total_net`; `total_net + vat_amount` vs `total_gross`. Product offers may carry `document` (a document ref, must exist: `product.offers[i].document: unbekannt: …`). USAGE of a company / material / component therefore lists the documents referencing it.

**Walls** (`shape.kind` = `rect` rectangular, or `roof` = top edge follows the storey roof; `gable` → error `gable noch nicht unterstützt`)
- Reference line, `outside`, inward normal `n`, shift `s`, layer bands, corners (mitre), T-joint (prepared), rooms and faces exactly as before: exterior wall `reference` `outside_face` | `center` | `inside_face`, `outside` `left`/`right`; interior wall `left_face` | `center` | `right_face`, `n` = right normal; point at wall coordinate `u` (along `d` from `start`) and depth `t` (from the first face) = `start + u·d + (t − s)·n`. At a corner every layer line of offset `t` is cut at the line of the same offset of the neighbour (deeper lines with the neighbour's innermost line); free ends square + warning `offenes Wandende`. An end that is no corner is a T-joint when it lies inside the band of a crossing wall (along `0…length`, depth `0…thickness`, tolerance) or inside the corner block of that wall with its corner neighbour (beyond the wall's end, inside the depth of both walls); corners are therefore determined for all walls before the T-joints. No warning for an end listed in the optional interior-wall field `free_ends` (`["start"|"end", ...]`, deliberately released end without a connection, no warning). `free_ends` on an exterior wall → error `free_ends nur bei Innenwänden`; other values → error `free_ends ungültig`. The wall object of `HOUSE` returns `free_ends` (`[]` if absent).
- For each face line `t` the module knows its `u` range `[u_a(t), u_b(t)]` (projection of its end points on `d`). Returned per wall: `u_range: {outside: [..], inside: [..]}` (exterior) resp. `{left, right}` (interior), and `ref_length` = length of the reference line.

**Openings** (`walls[].openings[]`)
- Fields: `id`, `component`, `offset`, `sill`, `joint` (default 0.01), `inset` (default 0.10), `reveal_material` (optional). `component` must be `opening_capable` (`Bauteil nicht für Öffnungen geeignet`) with class geometry `window`, `door` or `passage`. For a `passage`, `depth`, `frame_width` and `inset` are 0 (the opening is a bare hole through the wall).
- **Rough opening** (Rohbauöffnung): `u0 = offset`, `u1 = offset + width + 2·joint`, `zb = sill`, `zt = sill + height + 2·joint` (wall-local `z`, 0 = storey floor) with `width`/`height` from the component.
- Checks (error, `where` = `storey:<id>.<wall>.<opening>`): `[u0, u1]` lies within the `u` range of **both** faces (`Öffnung ragt über die Wand`); `zt ≤ height` of the wall (`Öffnung höher als die Wand`); two openings of a wall whose rough rectangles overlap by more than 0.0001 m² (`Öffnungen überlappen`); `inset + depth ≤ thickness` (`Bauteil tiefer als die Wand`); opening ids unique within the storey. These are **opening errors** (flag `kind: "opening"` in the error object).
- **Layer pieces:** every layer is split around the rough openings: break points = all `u0`/`u1` of the wall; each slab between consecutive break points (plus the two end slabs) = the layer footprint clipped by the half-planes `u ≥ a` and `u ≤ b` (Sutherland–Hodgman); within a slab the free height intervals = `[0, height]` minus the `[zb, zt]` of the openings covering the slab; one piece per (slab, free interval) with `footprint`, `z0`, `z1` (absolute), `volume` = area × (z1 − z0). Empty slabs (area < 1e-9) are dropped. Layer `volume` = sum of its pieces.
- **Faces:** face areas subtract the rough openings: outside = `length × height − Σ rough areas`; inside segments subtract `overlap(segment u range, [u0, u1]) × (zt − zb)` per opening.
- **Reveals** (Laibung, material = `reveal_material`, else none): on the four sides of the rough opening (bottom only if `sill > 0`), in two depth zones `t ∈ [0, inset]` and `t ∈ [inset + depth, thickness]`; returned as `reveals: [{side: left|right|top|bottom, material, area, quads: [[[x, y, z] × 4], ...]}]`; area = side length × (thickness − depth).
- **Parts of the component** (oriented boxes `{kind, material, center: [x, y, z], size: [along d, along n, height], direction}` in absolute coordinates), placed in the clear opening `[u0 + j, u1 − j] × [zb + j, zt − j]`, depth `t ∈ [inset, inset + depth]`, `fw` = `frame_width`:
  - `window`: `frame` (role `frame`): left, right, bottom, top bars of width `fw`, full depth; `n = max(sashes, 1)` panes of equal width separated by `n − 1` vertical `mullion`s (role `frame`) of width `fw`; for every pane a `glass` box (role `glazing`, thickness 0.024, centred in depth) and, when `sashes` ≥ 1 and the pane's opening type is not `fixed`, a `sash` ring (role `frame`, 4 bars of width `0.6 · fw`, depth `0.8 · depth`) around the pane. Returned per opening additionally `pane_openings` = list of the effective opening types (`fixed` for `sashes` = 0).
  - `door`: `frame` left, right, top (no bottom); `leaf` (role `leaf`) filling the inside of the frame from the clear bottom up to the top bar, thickness `0.6 · depth`, centred in depth.
  - `passage`: no parts. Its reveals cover the full wall depth in one zone `t ∈ [0, thickness]`.
  - Part volume = product of the size.
- Returned per opening: `{id, component, name, class, geometry, params, offset, offset_right (= ref_length − u1), sill, joint, inset, reveal_material, rough: {u0, u1, zb, zt, width, height, area}, plan: {outside: [p(u0,0), p(u1,0)], inside: [p(u0,T), p(u1,T)]}, swing, sashes, reveals, parts}`.

**Outline** (Umriss)
- The exterior walls of a storey are chained into **rings** through shared end points (tolerance 0.001 m), **independent of the direction** of each wall: start at any unused wall, walk to the wall sharing the current free end point, reversing walls as needed. Every closed ring is returned as `outline: [{points (outer face corners, i.e. the `t = 0` corner points), inner (the `t = thickness` corner points), walls: [ids], area}]` (outer polygon oriented consistently, area > 0). A chain that does not close → warning `Umriss nicht geschlossen`. For rooms and the foundation the ring with the largest area is used.
- Corner points of the ring = the mitred `t = 0` (outer) and `t = T` (inner) end points of the walls, so reflex (einspringende) corners are handled like convex ones.

**Foundation**
- Either `rect` `[x, y, w, h]` (as before) or `follow: "outline"` with optional `overhang` (m, default 0): the polygon is the outer ring of the ground storey, offset outwards by `overhang` (every edge moved along its outward normal, consecutive edges intersected; axis-parallel only). Returned as `foundation.polygon` (and `rect` = its bounding box). If the outline is not closed, the foundation is not computed (warning `Bodenplatte nicht berechnet – Umriss des Erdgeschosses nicht geschlossen`, no volume, no on-foundation check) – so walls can be edited step by step. Volume per layer = (polygon area − area of the `cutouts` inside it) · thickness. Optional `cutouts: [[x, y, w, h]]` (holes through the slab, e.g. above a basement stair; w, h > 0, else error `Aussparung ungültig` at `house.foundation.cutouts.<i>`, ignored) are returned as `foundation.cutouts` (ccw polygons, key only present when there are cutouts); the on-foundation check uses the outer polygon only. Layers downwards from `top`. `plinth` present → warning `Sockel noch nicht unterstützt`.
- `Wand nicht auf der Bodenplatte`: a wall footprint point lies outside the foundation polygon (tolerance 0.001; points on the boundary count as inside).

**Ceilings** (`storey.ceilings[]`)
- `assembly` must exist (`unbekannt: …`) and be category `slab` (`<ref> ist keine Decke (slab)`); its layers are `top_down`. `outline: "storey"` (default) = the `inner` polygon of the largest outline ring of that storey (clear inner faces of the exterior walls); if there is no closed ring → warning `Decke nicht berechnet – Umriss des Geschosses nicht geschlossen`, ceiling skipped. Otherwise `outline` is an explicit polygon.
- Height: `zc = elevation + (z ?? height)` is the **top edge of the assembly** and the **underside of the joists**. Layer `i` spans `z1 = zc − offset`, `z0 = z1 − thickness` (lining hangs below the joists); `volume = area × thickness`; the layer's optional `direction` is passed through.
- `joists` (separate element, not part of the assembly): `material` must exist (`unbekannt: …`, where `<storey>.<ceiling>.joists`); `width`, `height`, `spacing` > 0. `direction: west_east` → beams run along x and are distributed in y (`south_north` the other way). Span = polygon extent across the beams; `n = max(1, round(span / spacing))` beams with centres at `lo + (i + 0.5) · span / n` (`spacing_actual = span / n`). Each beam = strip of `width` across the polygon bounding box, clipped to the polygon; `length = clipped area / width`, `volume = clipped area × height`; z from `zc` to `zc + height`; empty strips are dropped.
- Output per storey: `ceilings: [{id, name, assembly, polygon, area, shaft_area, z_bottom, z_top, thickness, layers: [{index, material, z0, z1, thickness, volume, direction, color}], joists: null | {material, width, height, spacing, spacing_actual, direction, estimated, z0, z1, count, length, volume, beams: [{polygon, center, length, volume}]}}]`. Ceiling assemblies and materials (layers and joist material) count as used for `materials` / `assemblies` of HOUSE.

**Structure** (`storey.structure[]`, Tragwerk: beams and posts that are not part of a wall or ceiling)
- `beam` (Unterzug): `{id, name?, kind: "beam", material, width, height, start: [x, y], end: [x, y], z_top?}` – a box of `width` (across the line, centred on it) × `height` along `start → end`; `z_top` (storey-local, default = storey `height`) is its top edge, so it can carry the ceiling joists.
- `post` (Stütze): `{id, name?, kind: "post", material, width, depth, position: [x, y], z0?, z1?}` – a box of `width` (along x) × `depth` (along y) centred on `position`, from `z0` (default 0) to `z1` (default storey `height`), storey-local.
- Errors (`where` = `<storey>.<id>`): unknown `kind` → `Tragwerk-Art unbekannt: <kind>`; `material` not a material → `unbekannt: <ref>`; a size ≤ 0 or missing, `start` = `end`, or `z1 ≤ z0` → `Maße ungültig`; duplicate id → `doppelte Tragwerk-id`. Invalid elements are skipped.
- Output per storey: `structure: [{id, name, kind, material, footprint (ccw polygon), z0, z1 (absolute), width, height (z1 − z0), length (beam: line length, post: z1 − z0), volume (footprint area × (z1 − z0)), color}]`. Structure materials count as used materials of HOUSE.

**Outdoor areas** (`storey.outdoor_areas[]`, e.g. a covered terrace)
- `{id, name, rect: [x, y, w, h]}` (w, h > 0, else error `rect ungültig`, where `<storey>.<id>`); not checked against the outline or the rooms (they lie outside the exterior walls). A roof over them is a ceiling with an explicit `outline`.
- Output per storey: `outdoor_areas: [{id, name, rect, area}]`.

**Roof structure** (`storey.roof_structure`, Dachstuhl – Pfettendach mit Mittelpfetten; needs `storey.roof`)
- `{material, estimated?, note?, rafters: {width, height, spacing}, purlins: {width, height, z_top}, foot_purlins: {width, height}, collars: {width, height, z}, slopes: [{id?, side: west|east, range: [a, b], end?}], ridge_purlins?: [{id?, range: [a, b], width, height}]}` (heights storey-local). Errors (`where` `<storey>.roof_structure`, the structure is then skipped): no roof → `Dachstuhl ohne Dach`; material → `unbekannt: …`; a size, spacing or height missing or ≤ 0 → `Maße ungültig`; side, range (ascending) or `end` (strictly between the eaves; default the ridge) wrong → `Dachfläche ungültig`; a ridge purlin without ascending range or with width / height missing or ≤ 0 → `Firstpfette ungültig`.
- "across" = the coordinate across the ridge (x for south_north), "along" the other one. **Rafters** per slope: positions along `range` like the joists (`n = max(1, round(length / spacing))`, centres at the bay middles); each a strip of `width` along, across from its eaves to `end`; bottom plane = the roof underside (knee + tan(pitch) · distance from the eaves), top = bottom + height / cos(pitch); length = across length / cos(pitch). **Middle purlins** (one per side with slopes): level box `width × height`, centre across at the eaves ± (z_top − knee) / tan(pitch), top = `z_top`, along the union of that side's ranges. **Foot purlins**: level box on the knee wall (centre = outer face of the exterior wall parallel to the ridge whose outer face lies within 0.05 of the eaves ± half its thickness, else eaves ± width/2), from the knee height up, same along range. **Collars**: one per west rafter reaching the ridge with an east rafter at the same position, beside it (offset (rafter width + collar width)/2), level from `z` to `z + height`, across between the points where the roof underside is at `z + height/2`. **Ridge purlins**: level box `width × height` centred on the ridge, top = ridge height (roof underside at the ridge), along its `range`; length = range length.
- Output per storey: `roof_structure: null | {material, estimated, note, members: [{id, kind: rafter|purlin|foot_purlin|collar|ridge_purlin, name, material, footprint, bottom_plane, top_plane, z0, z1, width, height, length, volume}], counts: {rafter, purlin, foot_purlin, collar, ridge_purlin}}` – planes `[a, b, c]` absolute (`z = a·x + b·y + c`), volume = width × height × length; ids `<slope id>-s<n>`, `purlin-<side>`, `foot-purlin-<side>`, `collar-<n>`, ridge purlin `id` or `ridge-purlin-<n>`; names `Sparren West/Ost`, `Mittelpfette West/Ost`, `Fußpfette West/Ost`, `Kehlbalken`, `Firstpfette`. Its material counts as used material of HOUSE.

**Roof covering** (`storey.roof_covering`, Dachdeckung; needs `storey.roof` and the faces `roof_structure.slopes`)
- `{assembly, estimated?, note?, eaves_overhang?, verge_overhang?, invoice?: {area}, openings?: [{id, kind?: window|chimney, name?, slope, component?, flashing?, y?, sill?, rect_plan?, parts?}], items?: [{component, measure: ridge|verge|eaves|invoice, per_m?}]}`. Errors (`where` `<storey>.roof_covering`, the covering is then skipped): no roof → `Dachdeckung ohne Dach`; assembly unknown → `unbekannt: …`, not category roof → `<ref> ist kein Dachaufbau (roof)`; overhang < 0 or no number → `Überstand ungültig`; no valid slopes → `Dachflächen fehlen (roof_structure.slopes)`.
- **Faces** (one per slope, same id): across from the eaves − / + `eaves_overhang` to the slope `end` (default ridge); along = the slope range, extended by `verge_overhang` at every end not shared with another slope of the same side. `area_plan` = rectangle, `area` = area_plan / cos(pitch), `area_net` = area − its openings. Base plane = rafter top (roof underside + rafter height / cos); the assembly layers (top_down) are stacked perpendicular to the slope on it: layer bottom = base + (thickness − offset − layer thickness) / cos, top = bottom + layer thickness / cos; layer area = `area_net`, volume = area_net × thickness.
- **Openings** (`where` `<storey>.roof_covering.<id>`): unknown slope → `Dachfläche unbekannt: …`; unknown component / flashing / part → `unbekannt: …`; window without component → `Bauteil fehlt`; missing numbers → `Maße ungültig`; window `sill` < knee → `Unterkante unter dem Kniestock`; outside its face → `Öffnung außerhalb der Dachfläche`. Window: lower edge where the roof underside is at `sill`, rising along the slope by component height (plan across = height × cos), along = `y` ± width/2, area = width × height, glass area = (w − 2·frame) × (h − 2·frame). Chimney: `rect_plan` [x, y, w, h], area = plan / cos, z0 = storey elevation, z1 = covering top at the ridge + 0.5. A rafter of the face (`<slope id>-s<n>`) overlapping the opening along → warning `Sparren geschnitten (<ids>) – Balkenwechsel nötig`.
- **Edges**: `eaves` = sum of the along lengths of all faces; `ridge` = along overlap of west and east faces both ending at the ridge; `verge` = per face end the across part not covered by an adjoining face of the same side, / cos. **Items**: `quantity` = edge length (unit `m`), with `per_m` = ceil(edge × per_m) (unit `pcs`), `invoice` = the component's `params.quantity`; `invoice_quantity` = `params.quantity`. Unknown component → `unbekannt: …`, other measure → `Messart ungültig: …`.
- Output per storey: `roof_covering: null | {assembly, estimated, note, eaves_overhang, verge_overhang, thickness, faces: [{id, side, name, across, along, end, polygon, area_plan, area, area_net, openings, base_plane, layers: [{index, material, thickness, bottom_plane, top_plane, area, volume, color}]}], openings: [{id, kind, name, component, flashing, parts, slope, side, across, along, size, area, glass_area, sill?, z0?, z1?, rafters_cut}], edges: {ridge, verge, eaves}, items: [{component, name, measure, per_m, quantity, unit, invoice_quantity, invoice_unit}], invoice: {area}, area, area_net, volume}`. Its assembly, layer materials, opening components (+ their materials), flashings and parts count as used in HOUSE.

**Stairs** (`storey.stairs[]`, Wangentreppe mit Setzstufen)
- `{id, name?, material, estimated?, note?, to_storey, risers, run: {rect: [x, y, w, h], direction: west|east|north|south, straight_steps}, turn?: {side: left|right, steps}, construction?: stringer|solid, tread_thickness, riser_thickness, stringer: {width, height}}` (`construction` default `stringer`; for `solid` the thicknesses and `stringer` are not needed). Errors (`where` `<storey>.<id>`, the stair is skipped): unknown `to_storey` → `unbekannt: …`, not higher → `Zielgeschoss liegt nicht höher`; material → `unbekannt: …`; rect, direction, side, sizes or `risers ≠ straight_steps + steps + 1` → `Maße ungültig`; going < 0.10 → `Lauf zu kurz (Auftritt x cm)`; going < 0.21 → warning `steile Treppe (Auftritt x cm)`.
- Run frame (`StairGeometry`): u from the start edge in `direction`, v from the side opposite the turn (plan y grows southwards; left of west = south); L = run length, W = width. rise = (to_storey elevation − elevation) / risers; going = (L − W if winders else L) / straight_steps. Straight tread i: u [(i−1)·going, i·going], v [stringer width, W − stringer width], top i·rise, thickness tread_thickness; its riser at u (i−1)·going (+ riser_thickness) from (i−1)·rise to i·rise − tread_thickness. Winders: wedges of the square u [L−W, L] around the pivot (L−W, W), front rays at −90 + 90·k/steps degrees (−90 = towards v = 0, 0 = towards u = L), each wedge = pivot, the two ray hits on the square edges (plus the corner (L, 0) when it lies between); tread top (straight + k)·rise, riser = strip of riser_thickness along the front ray inside the wedge. Stringers: two boards (v [0, sw] and [W − sw, W]) over the straight run, bottom plane z = rise/going · u from the floor, top = bottom + height / cos, volume sw · height · length / cos.
- **Solid stair** (`construction: solid`, massive Betontreppe): no treads, risers or stringers; step i (straight) = block u [(i−1)·going, i·going], v [0, W], from the storey floor up to i·rise; winder k = its wedge from the floor up to (straight + k)·rise; kind `step`, name `Stufe n`, `counts: {step}`; the stair output then carries `construction: "solid"` (stringer stairs have no `construction` key).
- Output per storey: `stairs: [{id, name, material, estimated, note, to_storey, risers, rise, going, height, parts: [{id, kind: tread|riser|stringer, name, material, footprint, z0, z1, bottom_plane?, top_plane?, color?, volume}], counts: {tread, riser, stringer}, volume}]` – ids `<stair id>-<kind>-<n>`, names `Trittstufe n`, `Setzstufe n`, `Wange n`; risers carry `color` `#F4F4F0` (painted). The material counts as used in HOUSE.

**Light wells** (`storey.light_wells[]`, Lichtschacht vor einem Kellerfenster)
- `{id, name?, wall, opening, width, projection, depth, terrain, wall_thickness, material, grating: {material, thickness}, estimated?, note?}`: clear width along the wall, clear projection from the outside face, clear depth below `terrain` (absolute z of the terrain = top of the well). Errors (`where` `<storey>.<id>`, the well is skipped): wall or opening unknown → `unbekannt: …`; not an exterior wall → `Lichtschacht nur an Außenwand`; material or grating material → `unbekannt: …`; a size missing or ≤ 0 or `terrain` no number → `Maße ungültig`; well floor `z_floor = terrain − depth` above the rough sill (`wall z0 + rough.zb`) → `Lichtschacht zu flach`.
- Frame: a along the wall from the centre of the opening's outside line (`plan.outside`), b away from the outside face (−`normal_in`); `t` = wall_thickness, `w/2` = width / 2, `p` = projection. Parts (prisms): `floor` (Sohle) a [−w/2−t, w/2+t], b [0, p+t], z [z_floor − t, z_floor]; `wall` 1 a [−w/2−t, −w/2], b [0, p]; `wall` 2 a [−w/2−t, w/2+t], b [p, p+t]; `wall` 3 a [w/2, w/2+t], b [0, p] – walls from z_floor up to terrain; `grating` (role grating material) a [−w/2, w/2], b [0, p], z [terrain − thickness, terrain].
- Output per storey (after `stairs`): `light_wells: [{id, name, wall, opening, material, grating_material, estimated, note, width, projection, depth, terrain, z_floor, area, parts: [{id, kind: floor|wall|grating, name, material, footprint, z0, z1, volume, color}], volume (all parts except the grating), grating_area (= width × projection)}]` – part ids `<well id>-<kind>-<n>`, names `Sohle`, `Schachtwand n`, `Gitterrost`. Part materials count as used in HOUSE.

**Facade** (Holzfassade Stülpschalung as the outermost layer of an exterior wall assembly; `FacadeBuilder` + `FacadeCutting`, built last from the serialized walls)
- Source: an exterior wall whose assembly (outside_in) has a layer with `cladding: {kind?: lap_siding, board_length, board_width, overlap, bottom?, paint?, estimated?}` (the first such layer); board material = that layer's material, board thickness = its thickness. Layers in front of it are its coating (e.g. the paint): `paint` defaults to the material of the first of them, their thickness pushes the boards inwards and the board parts span t [0, coating + board thickness]; parts carry `layer` = the board layer index. Errors (`where` `<storey>.<wall id>`, that wall gets no boards): material or paint unknown → `unbekannt: …`; a board size missing or ≤ 0, `overlap` not in [0, board_width) or `bottom` no number → `Maße ungültig`. No substructure is modelled; the storey result uses the cladding of the first clad wall.
- Every clad wall gets horizontal rows on its outside face (u range `outside`): cover = board_width − overlap, row k spans z [bottom + k·cover, + cover] (storey-local) while its bottom is below the highest profile point. A row is cut out where a rough opening overlaps [z_lo, z_lo + board_width]; butt joints on a grid of board_length from the outside u start, every second row shifted by board_length / 2. Each piece is clipped at the wall profile (split at profile breaks and where the roof line crosses the row bottom / top); a sub-piece with the roof line inside the row gets `top_plane` (absolute plane through the cut), sub-pieces under the row bottom are dropped. Parts are prisms in the wall's outer layers (coating + boards), z0 = elevation + z_lo, z1 = top (− 0.004 shadow joint when the full cover is shown). Piece length = u extent of its sub-pieces; area = visible area (cover strip below the roof).
- Cutting: first-fit decreasing of the piece lengths into stock boards of board_length, offcuts < 0.5 m are waste. board_area = area · board_width / cover, volume = board_area · thickness, paint_area = board_area (0 without paint).
- Output per storey (key `facade` after `roof_covering`): `null | {kind, assembly, material, paint, estimated, board: {length, width, thickness}, overlap, cover, bottom, walls: [{wall, name, rows, pieces, length, area}], parts: [{id (<wall>-r<row>-<n>), wall, row, material, footprint, z0, z1, top_plane, length, color (paint colour)}], pieces, length, area, board_area, volume, boards, stock_length, waste_length, waste_share, paint_area}`. Material and paint count as used in HOUSE; counts `facade_parts`.

**Interior linings** (Innendämmung on rectangles of a wall face; `LiningBuilder` + `LiningGeometry`, built after the facade from the computed walls)
- Source: `wall.linings[]` `{id, assembly, face, u0, u1, z0?, z1?, note?}`. The assembly has category `interior_lining` with `layer_order: wall_out` (layers from the wall surface into the room). `face`: exterior wall `inside`, interior wall `left` | `right`. `u0`/`u1` along the wall from its start (reference line, like `opening.offset`), `z0` (default 0) / `z1` (default the highest point of the wall top) storey-local. The lining lies in front of the face (wall axes, faces and rooms unchanged); openings are cut out, reveals are not lined.
- Errors (**lining errors**, flag `kind: "lining"` with `wall` and `lining`, `where` `<storey>.<wall>.<lining>`; the lining is skipped): not an object → `Dämmbereich ungültig`; assembly unknown → `unbekannt: …`; category not `interior_lining` → `Aufbau ist keine Innendämmung (category interior_lining)`; no layers or a layer material unknown → `Schichten der Innendämmung ungültig`; face not allowed → `Seite ungültig (Außenwand: inside, Innenwand: left|right)`; a size no number, `u1 ≤ u0`, `z1 ≤ z0` or `z0 < 0` → `Maße ungültig`; `[u0, u1]` outside the u range of the face (± 0.001) or `z1` above the wall top → `Dämmbereich außerhalb der Wand`; overlapping an earlier lining of the same face → `Dämmbereich überlappt <id>`. Duplicate lining ids in the storey → error `doppelte Dämmbereich-id` (where `<storey>.<id>`).
- Pieces: the rectangle is split at its ends, at the sides of every rough opening, at the kinks of the wall top and where the wall top crosses `z1`; in each slab the top is `min(z1, top(u))` (linear), the free height intervals from `z0` exclude the rough openings; the last interval ends at the top (sloped → `top_plane`). `gross_area` = rectangle below the top, `area` = sum of the pieces, `opening_area = gross_area − area`.
- Layers: layer i lies at depth `d_i` (sum of the thicknesses before it) in front of the face: t `[thickness + d_i, thickness + d_i + th_i]` (inside / right) or `[−d_i − th_i, −d_i]` (left); every layer has `area` = lining area and `volume = area · th_i`. Parts are prisms per layer and piece: `{id <lining>-<layer+1>-<n>, lining, wall, layer, material, footprint, z0, z1 (absolute), top_plane, color}`.
- Output per storey (key `linings` after `facade`): `[{id, wall, wall_name, face, assembly, name, note, u0, u1, z0, z1, thickness, gross_area, opening_area, area, volume, openings: [ids cut], layers: [{index, material, thickness, area, volume}], parts}]`. Assemblies and layer materials count as used in HOUSE; counts `linings`.

**Rooms** (`storey.rooms[]`, IfcSpace; `RoomParser`, `RoomBuilder`, `OrthoPolygon`)
- `{id, number?, name, usage?, height?, polygon, ifc?, estimated?, note?, coverings?, furniture?}`. `polygon` = clear inner size (finished inner surfaces) as a closed ring `[[x, y], …]` (≥ 4 points, no repeated end point), **rectangular**: every edge axis-parallel (`|dx| < 0.0005` or `|dy| < 0.0005`). Errors (where `<storey>.<id>`, the room is skipped): not ≥ 4 number pairs → `Polygon ungültig (mindestens 4 Punkte [x, y])`; two consecutive points closer than 0.001 → `Polygon hat doppelte Punkte`; an oblique edge → `Polygon nicht im 90°-Raster (Kante <n>)`; after removing collinear middle points fewer than 4 points or two non-adjacent edges touching → `Polygon überschneidet sich selbst`. The points are stored counter-clockwise without collinear points. Not skipped: `usage` not in `NUF1` … `NUF7`, `TF8`, `VF9` (DIN 277) → `Nutzung ungültig: <usage>`; `height` not a number > 0 → `Raumhöhe ungültig`; a `number` used twice in the house → error `doppelte Raumnummer: <number>` (after all storeys). Several rooms may share a name (e.g. `Abseite`); floors and heating address all rooms of a name.
- **Rects**: the polygon is decomposed into non-overlapping rects (horizontal bands between the vertex ys, a band rect continued downwards while its x span stays the same); floors, heating, wall faces, the orientation check and penetrations use these rects. Room `area` = polygon area, `perimeter` = outline length.
- Checks: every rect inside the outline (all four corners, shrunk by 0.001, inside the inner polygon of the largest ring, else `Raum liegt nicht innerhalb der Außenwände`); rect overlap with an earlier room > 1e-6 m² → `überlappt mit Raum <id>`; every polygon edge midpoint on a wall face segment (else warning `Raumkante ohne Wand (Kante <n>)`). Wall face room segments are taken from the polygon edges.
- Height: `floor_top` = `z_top` of the first floor naming the room (else the elevation); `height` = the given height, else `elevation + storey height − floor_top` (≥ 0); `volume = area × height`.
- Output per storey: `rooms: [{id, number, name, usage, usage_name, estimated, note, polygon, rects, area, perimeter, height, volume, floor_top, wall_area, faces: [{wall, side, length, area, material, line}], source, coverings}]` (`usage_name` German DIN 277 name; `source` = the complete room JSON of the file, also invalid coverings, for the room editor).

**Coverings** (`room.coverings[]`, Beläge, IfcCovering; `CoveringBuilder` + `WallCoveringBuilder`, after the floors)
- `{id, name?, surface: floor|wall, assembly, area?, walls?, z?, estimated?, note?}`; the assembly has category `covering` (`layer_order: wall_out`, layers from the substrate into the room). **Covering errors** (flag `kind: "covering"` with `room` and `covering`, where `<storey>.<room>.<covering>`; the covering is skipped): not an object → `Belag ungültig`; assembly unknown → `unbekannt: …`; category not `covering` → `Aufbau ist kein Belag (category covering)`; no layers or a layer material unknown → `Schichten des Belags ungültig`; `surface` other → `Fläche ungültig (floor oder wall)`. Covering ids unique in the storey (error `doppelte Belag-id`).
- **Floor**: `area` `"room"` (default, the whole room) or a rectangular zone polygon (polygon errors as for rooms, prefixed `Bereich: `); a zone not lying in the room (rect overlap < zone area − 1e-6) → `Belagsbereich liegt nicht im Raum`. Zones overlapping each other (> 1e-6 m²) → `Belagsbereiche überlappen: <id>`; more than one whole-room covering → `mehrere Beläge für den ganzen Raum` (both not skipped). Zones replace the whole-room covering where they lie; shafts through the storey floor are cut out: zone `area = gross_area − shaft_area`; whole room `zone_area` = sum of the zone gross areas, `shaft_area` = shaft overlap with the room minus that with the zones, `area = gross_area − zone_area − shaft_area`. `z0` = room `floor_top`, `z1 = z0 + thickness`.
- **Wall**: `walls` `"all"` (default, every wall face segment bounding the room) or `[{wall, u?: [u0, u1]}]` (`u` along the wall from its start like `opening.offset`); `z` `[z0, z1]` storey-local (default `[0, top]`). Unknown wall → `Wand unbekannt: <id>`; a wall without face segment of the room → `Wand <id> grenzt nicht an den Raum`; `walls` no list / empty → `Wände ungültig ("all" oder [{wall, u}])`; `u` or `z` invalid (`u0 < u1`, `0 ≤ z0 < z1`) → `Maße ungültig`; no segment left → `Wandbelag ohne Wandfläche`. Per room face segment: u range = its line projected on the wall (clipped to `u`), z1 clipped to the lowest wall top over the range (roof walls approximated); every rough opening overlapping u and z removes its u overlap from the `length` and its u × z overlap from the `area`. Segment `line` = the face line between the two u.
- Layers: `[{index, material, thickness, offset, area, volume, color}]` with `area` = covering area, `volume = area · thickness`.
- Output in `room.coverings`: floor `{id, name, surface, assembly, assembly_name, thickness, estimated, note, source (the covering JSON of the file), scope: room|zone, polygon (zone, else null), rects, gross_area, shaft_area, zone_area, area, z0, z1, layers, volume}`; wall `{… common, scope: "wall", z0, z1, segments: [{wall, side, u0, u1, z0, z1, line, length, area, openings}], length, area, layers, volume}`. Assemblies and layer materials count as used in HOUSE; counts `coverings`.

**Shafts** (`house.shafts[]`, Schächte, IfcOpeningElement; `ShaftBuilder`)
- `{id, name, purpose?: supply|ventilation|chimney|other, polygon, from_storey, to_storey, penetrations?: [tga-run refs], ifc?, estimated?, note?}`. Errors (where `house.shafts.<id>`, the shaft is skipped): invalid or duplicate id → `Schacht-id ungültig oder doppelt`; polygon errors as for rooms; storey unknown → `unbekannt: …`; `from_storey` not higher than `to_storey` → `oberstes Geschoss liegt nicht über dem untersten`.
- Before the storeys: the shaft opens the **floors** of every storey with `to.elevation < elevation ≤ from.elevation` and the **ceilings** of every storey with `to.elevation ≤ elevation < from.elevation` (the lowest floor stays closed). Floor rooms get `shaft_area` = overlap of their rects with the shaft rects and `area` = gross − shaft_area; ceilings get `shaft_area` = their polygon inside the shaft rects and `area` = polygon area − shaft_area (layer volumes follow); joists are not cut.
- After the storeys and the TGA: `cuts: [{storey, kind: floor|ceiling, element, name, area}]` (> 1e-6 m²); warnings `Schacht liegt in <storey> nicht vollständig in einem Boden` (floor cuts < shaft area − 0.001), `Heizkreis <id> liegt im Schacht` (circuit rect overlap), `Deckenbalken von <ceiling> im Schacht – Wechsel nötig` (a joist beam overlaps); `penetrations`: a ref that is no waste water / drinking water run → error `Leitung unbekannt: <ref>`; no run point within 0.01 of the shaft rects → error `Leitung <ref> verläuft nicht im Schacht`.
- Output HOUSE key `shafts: [{id, name, purpose, from_storey, to_storey, polygon, rects, area, floor_storeys, ceiling_storeys, penetrations, estimated, note, source, cuts, cut_area}]` (storeys from top to bottom; `source` = the shaft JSON of `house.json`); counts `shafts`.

**Floors** (`storey.floors[]`, Fußbodenaufbau KG 352)
- `{id, name?, assembly, rooms: [<room name>], z?, estimated?, note?, offer?}`. `assembly` must exist (`unbekannt: …`) and be category `slab` (`<ref> ist kein Bodenaufbau (slab)`), its layers `top_down`. A room is addressed by its **name**: every room of the storey with that name belongs to it (several rooms may share a name); a name without room → error `Raum unbekannt: <name>` (where `<storey>.<floor id>`). Bottom `z_bottom = elevation + (z ?? 0)`, `z_top = z_bottom + thickness`; layer `i` spans `z1 = z_top − offset`, `z0 = z1 − thickness`, `area` = floor area, `volume = area × thickness`, `heated` = the layer's flag (pipe level of a floor heating). Room entry `rects` = the rects of all rooms of that name, `shaft_area` = their overlap with the shafts opening this floor, `area` = sum of the rects − shaft_area, `edge_length` = perimeter of the union of its rects (sum of the rect perimeters minus twice every edge shared by two rects of the room; doors are not subtracted).
- `offer` `{company, document?, date?, items: [{pos, name, material?, measure: area|edge|offer, quantity, unit, unit_price}]}`: company unknown → error `unbekannt: …` (where `<storey>.<floor id>.offer`); `document` is free text or a document ref (`document:…`, must exist, else the same error); per item `model_quantity` = floor area (`area`), edge length (`edge`) or the offered quantity (`offer`), `offer_total = quantity × unit_price`, `model_total = model_quantity × unit_price`; items without numeric `unit_price` are skipped.
- Output per storey: `floors: [{id, name, assembly, estimated, note, z_bottom, z_top, thickness, area, edge_length, rooms: [{name, rects, area, shaft_area, edge_length}], layers: [{index, material, z0, z1, thickness, area, volume, heated, color}], offer: null | {company, company_name, document, document_name, date, items: [{pos, name, material, measure, unit, quantity, model_quantity, unit_price, offer_total, model_total}], offer_total, model_total}}]`. Floor assemblies and their layer materials count as used in HOUSE.

**Floor heating** (`storey.heating`, Fußbodenheizung KG 420, parametric pipe layout)
- `{name?, pipe?, pipe_diameter, floor, estimated?, note?, manifold: {name?, position: [x, y], width?}, circuits: [{id, name?, room, rect: [x, y, w, h], cutout?: [x, y, w, h], pattern: spiral|meander, spacing, edge?, entry: nw|ne|sw|se, feed: [[x, y], …], color?}]}` (`pipe` = a `tga-component:` ref, passed through, not resolved). Errors (where `<storey>.heating`, the heating is skipped): `floor` not in the computed floors → `Boden unbekannt: <id>`; its assembly without `heated` layer → `Aufbau ohne Rohrebene (heated): <ref>`; `pipe_diameter` missing or ≤ 0 → `Maße ungültig`; manifold position not a point → `Verteiler ungültig`. Pipe level `z` = `z0` of the first heated layer + pipe_diameter / 2 (the pipe lies on the knob plate); the manifold is drawn at that z, `width` default 0.5.
- Circuit errors (where `<storey>.heating.<circuit id>`, circuit skipped): rect / spacing / edge (default 0.10) / entry / feed points invalid → `Maße ungültig`; `spacing < 0.075` → `Verlegeabstand zu klein (<cm> cm)`; empty layout → `Verlegefläche zu klein`; `cutout` (unheated corner, e.g. shower tray) not a rect inside `rect` touching one of its corners (and smaller than it in both directions) → `Aussparung ungültig (muss in einer Ecke der Verlegefläche liegen)` (circuit laid without cutout). Not skipped: room name without rects → `Raum unbekannt: <name>`; rect not covered by the rects of that room (sum of the intersections < rect area − 0.001) → `Heizkreis liegt nicht im Raum <name>`; two circuit rects overlapping (> 0.001 m²) → error `Heizkreise überlappen: <a>, <b>` (where `<storey>.heating`); total length > 100 m → warning `Heizkreis zu lang (<n> m)`.
- **Layout** (`PipeLayout`, bifilar): a centre line with pitch `2 · spacing`, starting `edge + spacing/2` inside the rect at the `entry` corner (local frame u, v from that corner into the rect, mirrored back to plan). `spiral`: the laying area is the rect, or with a `cutout` the L-shaped polygon left by it; ring k = that polygon moved inwards by `edge + spacing/2 + k · pitch` (edge offset with intersected neighbours). A ring is valid while every edge keeps its direction and its bounding box is ≥ pitch in both directions; when an L ring becomes invalid, the rings continue in the larger rect beside the cutout (`x` side or `y` side, larger area) moved in by the same depth, until that is < pitch. Each ring starts at its vertex nearest to the entry corner, runs first along x (away from the entry corner), around all vertices and stops one pitch before its start on the closing edge; from there the line steps to the next ring (for a plain rect this is the rectangular spiral). `meander`: rows along the longer side of the rect at `v = inset + k · pitch` (while ≤ depth − inset), alternating direction, from inset to length − inset. The centre line is cleaned (duplicates and collinear middle points removed). Supply = centre line moved by `+spacing/2`, return = moved by `−spacing/2` (mitred offset: vertex = point + (n1 + n2) · d / (1 + n1·n2)), so neighbouring pipes are `spacing` apart; `field` = supply followed by the reversed return (they meet at the far end). Feed: the `feed` points plus the first centre point, moved by ±0.025 (5 cm apart); the moved line whose end is nearer to the supply start is `feed_supply`, its last point replaced by the supply start (likewise `feed_return` with the return start).
- Lengths: `length_field` = polyline length of `field`, `length_feed` = both feed lines, `length` = sum; `area` = rect area minus the cutout area.
- Output per storey: `heating: null | {name, pipe, pipe_diameter, floor, estimated, note, z, manifold: {name, position, width, z}, circuits: [{id, name, room, color, pattern, spacing, entry, rect, cutout, area, field, feed_supply, feed_return, length_field, length_feed, length}], area, length}` (points `[x, y]`, all at `z`).

**Wall heating** (`storey.wall_heating`, Wandheizung KG 420, panels in fields on the room faces of walls; `WallHeatingBuilder` + `WallHeatingField`, built after the walls)
- `{name?, assembly, panel_components: {<type letter>: tga-component ref}, pipe?, pipe_diameter? (default 0.0116), feed_diameter? (default 0.016), coupling?, adapter?, supply_temperature?, return_temperature?, estimated?, note?, distributor: {name?, component?, wall?, position: [x, y], z?, width?, height?, outlets?, note?}, duct?: {name?, rect: [x, y, w, h]}, circuits: [{id, name?, room?, design_area?, design_output?, color?}], fields: [{id, name?, circuit, room, wall?, origin: [x, y], direction: [dx, dy], panels: [{type, u, z, rotated?}], port_u, feed: [[x, y], ...]}]}`. Errors (where `<storey>.wall_heating`, the wall heating is skipped): assembly unknown → `unbekannt: <ref>`, not category `interior_lining` → `<ref> ist keine Innenbekleidung (interior_lining)`, without `heated` layer → `Aufbau ohne Plattenebene (heated): <ref>`, pipe_diameter ≤ 0 → `Maße ungültig`, distributor position not a point → `Verteiler ungültig`. Not skipped: distributor wall / component unknown → `Verteiler: Wand unbekannt: …` / `Verteiler: unbekannt: …`; more circuits than `outlets` → `Verteiler hat nur <n> Abgänge für <m> Heizkreise`; `coupling` / `adapter` unknown → `<key>: unbekannt: <ref>`, without an end DN equal to a panel end DN → `<ref> passt nicht zu den Plattenanschlüssen (DN …)`, adapter without an end DN = feed_diameter in mm → `Übergang <ref> passt nicht zur Anbindeleitung <mm> mm`.
- Panel layer: the first `heated` layer of the assembly (layer order `wall_out`, offset from the wall face); the pipe lies at depth `offset + thickness − pipe_diameter/2 − 0.004` (grooves on the room side). Distributor axis = direction of its wall (else x); output z = storey z0 + `z`, width default 0.4, height 0.5, depth 0.1.
- Field (where `<storey>.wall_heating.<field id>`, field skipped on errors): circuit unknown → `Heizkreis unbekannt: <id>`; origin / direction (unit, axis-parallel) / port_u invalid → `Maße ungültig (origin, direction achsparallel, port_u)`. Frame: `d` = direction, `n` = (−dy, dx) into the room, u along d, z storey-local. Panel (where `….panels[<i>]`, panel skipped): u / z not numbers → `Maße ungültig`; type not in `panel_components` or component missing → `Plattentyp unbekannt: <type>`; class not `tga-class:wall-heating-panel` or without width / height → `<ref> ist keine Wandheizungsplatte`. A panel covers u..u+width, z..z+height; corners at the front of the panel layer, the pipe is a meander at pipe depth (runs along `pipe_direction` vertical / horizontal, spacing `pipe_spacing` default 0.10, margin spacing/2, starting at the left bottom, mirrored in u when `port_corner` ends with `right`); `pipe_length` = component param, else the meander length; area = width · height; `rotated: true` = laid turned by 90° (landscape instead of portrait: width and height swapped, pipe_direction vertical ↔ horizontal). No panel left → `Feld ohne Platten`. `links`: consecutive panels (in panel order) joined from the last pipe point of one to the first of the next, `{from, to, points [start, middle, end], coupling (= spec coupling), position (middle = press coupling), length}`. One joint per pipe end, no branch: a link that passes within 5 mm of the first or last pipe point of a panel it does not join → warning `Abzweig: Verbindung <from> -> <to> läuft durch <Anfang|Ende> von Platte <i> (<type>)` (scripts/inspect_wall_heating_ports.py lists them).
- Field checks: two panels overlapping (> 0.5 mm both ways) → error `Platten überlappen: <i> (<type>), <j> (<type>)`; room name without rects → `Raum unbekannt: <name>`; back points (u0 + 1 cm, u1 − 1 cm) outside the room rects → error `Platte <i> (<type>) liegt nicht im Raum <room>`; roof height at u0 or u1 below the panel top → error `… ragt über die Dachschräge`; an opening of any wall whose inside or outside plan points lie in the field plane (≤ 2 cm) and that overlaps the panel (rough zb..zt) → warning `… überdeckt Öffnung <id>`; port_u not on the bottom edge of a lowest panel → warning `Anschluss liegt an keiner Plattenunterkante (u <u>)`; no feed points → `Anbindeleitung fehlt`. Feed: the feed points plus the port (plan), cleaned, offset ±0.02 (supply +, return −); the points start at the distributor z, run at storey z0 + 0.03 and rise at the end to the port z.
- Circuit (where `….<circuit id>`): no field → warning `Heizkreis ohne Plattenfeld`; area differs from `design_area` by > 0.05 m² → warning `Heizfläche <a> m² weicht von der Auslegung <d> m² ab`. Per field `couplings` = panels − 1, `adapters` = 2.
- Output per storey (key `wall_heating` after `linings`): `null | {name, assembly, pipe, pipe_diameter, feed_diameter, coupling, adapter, supply_temperature, return_temperature, estimated, note, layers: [{index, material, thickness, heated}], distributor: {name, component, wall, position, axis, z, width, height, depth, outlets, note}, duct: null | {name, rect, z0}, circuits: [{id, name, room, color, fields, panel_count, area, design_area, design_output, pipe_length, feed_length, couplings, adapters}], fields: [{id, name, circuit, room, wall, wall_name, origin, direction, normal, panels: [{index, type, component, name, u0, u1, z0, z1, width, height, pipe_direction, rotated, port_side, depth, corners, pipe, area, pipe_length, estimated}], links, port: {u, position}, feed_supply, feed_return, area, pipe_length, feed_length, couplings, adapters}], counts: {<type>: n}, panel_count, area, pipe_length, feed_length, couplings, adapters}` (points absolute `[x, y, z]`).

**Waste water** (Abwasser KG 411, `TgaLoader` + `WasteWaterBuilder`, computed after all storeys)
- `TgaLoader` reads `catalog/tga-classes`, `catalog/tga-components` (refs `tga-class:` / `tga-component:`), `house/tga/terminals`, `house/tga/runs` (refs `tga-terminal:` / `tga-run:`) and `house/penetrations.json` `items` into `model["tga"] = {elements, terminals, runs, parts, penetrations}` (file id must match the name, else `id passt nicht zum Dateinamen`). The main catalog, `REF_RE` and the catalog pages are untouched.
- A run belongs to the waste water when its component has `params.medium == waste_water`; line `system_line` (`ht`|`kg`, default `ht`), `dn` = `nominal_size_dn`, `outer_diameter`, colour HT `#9AA0A6`, KG `#C0602A`. `points` = ≥ 2 absolute `[x, y, z]` (else `points: mindestens 2 Punkte [x, y, z]`); flow runs from the first to the last point. Per segment `length`, `plan_length`, `slope` = fall / plan length (`null` when vertical: plan < 1 mm or < 1 % of the length). Errors: duplicate point `doppelter Punkt`; rising by > 1 mm `Gegengefälle (<cm> cm steigend)`; warning `Gefälle <x> % < <min> %` when the slope + 0.05 % is below `min_slope` (default HT 0.02, KG 0.01).
- `into {run, kind}`: `continue` – the last point must equal the first point of the target (1 cm, else `Ende trifft nicht den Anfang von <id>`); `branch` – the last point must lie within 1 cm of the target axis (`Ende liegt nicht auf der Achse von <id>`), warning `Abzweig DN <a> größer als Leitung DN <b>`; unknown target → `Leitung unbekannt`. A run without `to` and `into` → warning `Leitung ohne Ziel (to / into)`. Used terminals unknown → `Endstelle unbekannt`.
- **Penetrations** (`PenetrationBuilder`, `SegmentPrism`): bodies = every wall (`footprint`, `z0..z1`, element `wall:<storey>/<id>`, exterior = category `exterior_wall`), ceiling (`polygon`, `z_bottom..z_top + joists.height`), floor (per room rect, `z_bottom..z_top`) and the foundation slab (`foundation:main`, its polygon – or, when the `follow: outline` slab could not be built, the bounding box of the exterior walls of the ground storey – from `top − thickness` to `top`, cutouts excluded). Each segment is intersected with each prism; consecutive inside pieces of the same element (also across a bend) form one hit; hits < 5 mm are dropped. `kind` = `embedded` when the hit is longer than 3 × the element thickness or runs along it (in a wall: more rise than plan length; in a slab: more plan length than rise), else `through`. Per hit `{element, element_name, element_kind, storey, source: "tga-run:<id>", run, run_name, kind, dn, outer_diameter, line, core_drill = ceil((od + 0.02) · 100) / 100, position (middle), length, direction vertical|horizontal|oblique (20 % rule), airtight (exterior), estimated, index}` (`index` counts the through hits of a run per element). Overrides of `penetrations.json` match `(element, source, index)` and copy `fire_stop_type`, `sealing`, `done`, `note`; an item without match → warning `verwaist: <element> / <source> #<index>`.
- **Fittings** (stage 2, `FittingResolver`, `FittingCatalog`, `PipeCutter`): fittings = components of `tga-class:pipe-fitting` (`fitting_type` bend|branch|adapter|plug, `system_line`, `dn`, `angle`, `dn_branch`, `line_to`, `dn_to`, `z_length` = length taken from the pipe per connection); pipes with `stock.lengths`. Every corner with a direction change ≥ 2° gets the fewest bends of the run's line/DN whose angles add up to it within 2° (up to 3); otherwise the closest combination and warning `Winkel <a>° nicht im Sortiment (gewählt <list>°)`, none at all → `kein Bogen …`. A run whose start is not continued from another run and that has no `from` or starts at a `stub` terminal gets a plug; a run whose `to` is a stub terminal gets one at its end (`kein Stopfen …`). `continue` between different line/DN → adapter (either orientation, `kein Übergang …`). `branch` → branch fitting of the target line/DN with `dn_branch` = run DN and the angle nearest to the junction angle (within 10°, else `Abzweigwinkel <a>° nicht im Sortiment`). Every fitting takes its `z_length` from the adjacent stretches (branch: from both sides of the split target segment). Each straight stretch is cut by `PipeCutter`: an offcut long enough first, else one cut from the shortest stick ≥ the rest, else full longest sticks; stretch shorter than its fittings → warning `Abschnitt zu kurz für die Formteile`.
- Output `model["waste_water"]` (and HOUSE key `waste_water`): `null | {runs: [{id, ref, name, component, component_name, line, dn, outer_diameter, color, installation, system, estimated, note, min_slope, points, segments: [{from, to, length, plan_length, slope, vertical}], length, from, to, into}], terminals: [{id, ref, name, component, component_name, terminal_type, storey, room, position, estimated}], penetrations, parts: [{run, run_name, component, name, fitting_type, at, angle, wanted, position, direction, outer_diameter, estimated}], stock: [{component, name, kind fitting|pipe, fitting_type, length (stick), count, estimated, note}], cuts: [{run, run_name, component, name, segment, length, net_length, pieces, deduction}], length, by_component: [{component, name, dn, line, length}]}`.

**Drinking water** (Zuwasser KG 412, `WaterSupplyBuilder` + `CrossingLoop`, computed after the waste water)
- A run belongs to the drinking water when its medium is `cold_water`, `hot_water` or `circulation`; the medium is `run.medium` (schema `tga-run`), else `component.params.medium` – so one pipe component serves cold and hot. Line `system_line` (default `ppr`), `dn` = `nominal_size_dn`, `outer_diameter` (default 0.02), colours (all green): cold `#1B7F3B`, hot `#8BC34A`, circulation `#4CAF7A`; `medium_name` Kaltwasser|Warmwasser|Zirkulation. No slope rules; segments `{from, to, length, plan_length, slope: null, vertical}`; duplicate point → `doppelter Punkt`; `points` check and `Endstelle unbekannt` as for waste water. The waste water ignores these runs (its component medium differs).
- **Crossing loops** (before segmenting): for every pair of runs and every pair of their segments with an angle ≥ 30° whose closest distance (segment–segment, both parameters strictly inside 0..1) is below `(od_a + od_b) / 2 + 0.005`, the run with more straight pipe on both sides of the crossing (distance to the segment ends and to every last point of another run lying within 1 cm of the segment = branch junction) gets a loop: offset `o = (od_a + od_b) / 2 + 0.01` along `n = ± d × e` (d = own, e = other direction), the sign whose probe point `c ± 0.03 n` lies farther (plan) from the edges of the wall footprints whose z range (± 0.5 m) contains the crossing – the loop bends away from the wall, `a = od / 2`; inserted points `c − d(o + a)`, `c − d a + n o`, `c + d a + n o`, `c + d(o + a)` (rounded 0.0001) → four 45° bends by the fitting resolver. Repeated until the pair has no crossing. Not enough room (`< o + a + 0.02`) → warning `Kreuzung mit <id> ohne Platz für die Schleife (<cm> cm frei)`, no loop.
- Fittings, cutting and penetrations as for waste water (`FittingResolver`, `PipeCutter`, `PenetrationBuilder`); the plug (`fitting_type plug`, here the end cap) goes to a run that starts at a `transfer` or `stub` terminal and to a run whose `to` is such a terminal (at its last point). `into {run, kind: branch}`: the last point of the run must lie within 1 cm of the target axis (`Ende liegt nicht auf der Achse von <id>`, unknown → `Leitung unbekannt`) → T-piece (branch fitting `dn_branch` = run DN). Terminals of type `wall_plate` (terminal class option) are counted as stock rows `{component, name, kind: "terminal", fitting_type: "wall_plate", length: null, count, estimated: false, note: null}`.
- Output `model["water_supply"]` (and HOUSE key `water_supply`): `null | {runs: [{id, ref, name, component, component_name, line, dn, outer_diameter, medium, medium_name, color, installation, system, estimated, note, points, segments, length, from, to, into}], terminals: [{… as waste water, wall}], loops: [{run, run_name, other, other_name, position, offset, segment, points}], penetrations, parts, stock, cuts, length}`.

**Electrical** (Elektrik KG 440, `ElectricalBuilder`, computed after the drinking water)
- A run belongs to the electrical system when the class of its component has `kind: cable`. Optional `conduit {pipe, bend, sleeve, clamp, clamp_spacing (0.5)}` (schema `tga-run`): pipe = install-part with `part_type conduit` and params `size`, `outer_diameter` (0.02), `inner_diameter`, `stock_length` (3.0); unknown pipe/part → error, other part_type → warning. `open_end {reserve (1.5), note}` = start left open (connection later), `reserve` (0.5) = cable reserve at the box. Colours by cores: 3 `#E53935`, 5 `#8E24AA`, else `#FB8C00`; conduit `#C9CDD2`; `label` = "<cable_type> <cores>x<cross_section>".
- Checks: `points` as for waste water, `doppelter Punkt`; a segment off the axes by more than 2 mm → warning `Strecke nicht achsparallel`; cable diameter (param `outer_diameter`, default 0.009) > 80 % of the inner diameter → error; neither `to` nor `open_end` → warning; run end more than 10 cm from its terminal → warning; `Endstelle unbekannt`.
- Parts (with position, direction): bend at every corner (`angle`), sleeve at every full stock length inside a segment, `ceil(length / clamp_spacing)` clamps per segment (≥ 1). Cuts per segment `{run, run_name, segment, pipe, net_length, pieces}` (pieces ≤ stock length); bars = first fit decreasing over all pieces of a pipe. Stock rows `{component, name, kind cable|pipe|fitting|box, fitting_type, length, count, packs, pack_size, unit_price, price_note, price, estimated, note}`: cable length = run length + reserves; packs = ceil(count / `pack_size`); unit price = lowest EUR offer (cable per m: offers "je m", else ring price / ring length from the name). Penetrations via `PenetrationBuilder` (`line` = conduit size, `dn` null). Shafts accept electrical runs in `penetrations`.
- Output `model["electrical"]` (and HOUSE key `electrical`): `null | {runs: [{id, ref, name, component, component_name, cable_type, cores, cross_section, label, cable_diameter, color, conduit, conduit_color, outer_diameter, dn, line, installation, system, estimated, note, points, segments, length, cable_length, from, to, open_end, reserve}], terminals: [{id, ref, name, component, component_name, terminal_type, size, storey, room, wall, position, estimated}], penetrations, parts, stock, cuts, length, cable_length}`. BOM `electrical: null | {runs, penetrations (through), parts, stock, cuts}` (`ElectricalTally`, after `water_supply`); totals `electrical_conduit_length`, `electrical_cable_length`, `electrical_price` appended last.

**Installed parts** (Einzelteile mit Anschlusspunkten, `PartBuilder`, `PartFrame`, `PartPorts`, `SlotBuilder`, computed after the electrical system)
- `TgaLoader` also reads `house/tga/parts` (ref `tga-part:`, schema `tga-part`) into `model["tga"]["parts"]`. A tga-component is placeable when it has an `install` block (schema `tga-component`: `trade` electrical|waste_water|water_supply, `group`, `shape` pipe|fitting|box|valve|cap|insert, `outer_diameter`, `size` [w, h, d], `stretch {max_length, default_length}`, `ports: [{id, pos, dir, at_length?, line ht|kg|ppr|conduit|insert, dn, gender spigot|socket|any}]` in the local frame x, y = wall plane, w = out of the wall); `scripts/build_ports.py` writes these blocks. A tga-component of `tga-class:cable` without an `install` block gets a derived one (`PartBuilder.install_of`): `{trade electrical, group Leitungen, shape cable, outer_diameter` = param `outer_diameter` or estimated `0.006 + 0.0008 × cores × √cross_section_mm2`, `stretch {default_length 1, max_length 50}`, ports `a` at the origin (dir −x) and `b` at_length (dir +x), line `power`, dn = core count (param `cores`, else number of `connection.conductors`, default 3), gender `spigot`}`; an explicit block wins. Optional `install.palette` (path or list of paths) overrides the palette tree paths.
- Part `{id, component, storey, host: {wall, face} | null, u, z, depth, rot {plane, tilt, turn, flip}, position, axes {x, y}, length, path, connections {port: "<part>.<port>"}, open_ok [ports], system, medium, cable, circuit, estimated, note}`. Errors (kind `part`, where `tga-part:<id>`, part skipped): component without install block `Komponente ohne Einbaudaten: <ref>`; storey not computed `Geschoss unbekannt: <id>`; length (stretch parts, default `default_length`) not > 0 `Länge ungültig` or > `max_length` `Rohr länger als <max> m`; free part without `position`/`axes` `freies Teil ohne position/axes`, degenerate axes `Achsen ungültig`; host wall not in the storey `Wand unbekannt: <id>`; face not `outside|inside` (exterior) / `left|right` (interior) `Wandseite ungültig (Außenwand: outside|inside, Innenwand: left|right)`; `u`, `z`, `depth` not numbers `Lage ungültig (u, z, depth)`. **Bent cables:** a cable part may carry `path` = list of local points `[x, y, w]` after the origin (port a); the last point is port b (direction = last piece), port a points against the first piece; legs = the polyline origin → points; `length` = sum of the pieces (rounded to 0.1 mm); a malformed path → `Leitungsverlauf ungültig (path: Liste von [x, y, w])`, length 0 or > 50 m → `Leitungslänge ungültig (0 bis 50 m)`. Without `path` a cable is straight (`length` along x like a pipe).
- **Frame** (`PartFrame`): hosted part: `d` = unit direction start→end, `n` = `normal_in`, face plane `t` = min (outside/left) or max (inside/right) of `(footprint − start)·n`, outward sign −1 / +1, `e_out = sign·n`; origin = `start + d·u + n·t + e_out·depth`, z = wall `z0 + z`; local vector → flip (x → −x), plane (about w), tilt (about x: y, w), turn (about y: x' = x cos + w sin, w' = −x sin + w cos), then `x·e_u + y·e_z + w·e_out` (`e_u = d`, `e_z` = up). Free part: origin `position`, x = unit `axes.x`, y = `axes.y` made orthogonal, w = x × y. Port world position = frame point of `pos` (`at_length`: `pos.x + length`), direction = frame vector of `dir`. Legs: pipe a→b, fitting/valve/cap origin → every port, box/insert none.
- **Ports** (`PartPorts`): two ports of different parts are seated when ≤ 2 mm apart and their directions opposite within 1°; compatible = same `line` and `dn`, spigot ↔ socket or one `any`. **Cables:** a cable end (line `power`, dn = cores) fits only a cable entry port whose `cores` list contains its core count, never another cable end; entry ports (conduit entries of boxes) carry `cores` (Gerätedose, Abzweigdose with WAGO clamps, Lampenfassung E27 `[3]`, Herd-Anschlussdose `[5]`); a conduit pipe with `cable` gets `cores = [<cores of the cable>]` on its conduit ends and fits an entry only when both `cores` overlap (an empty conduit fits every entry). Seated and compatible → `connected_to` (each port at most once, in part/port order); seated but incompatible → warning `Anschluss <p> passt nicht zu <part>.<q> (<line> DN <dn> / <line> DN <dn>)`. A free (not joined) port whose nearest port of another part (ports joined to this part itself excluded) is closer than 3 cm (wrong angle / position, the other port already taken – one part per port –, or a misfit; a seated free pair is reported above instead) → warning `Anschluss <p> liegt an <part>.<q> ohne Verbindung (<mm> mm)`. Stored connections: unknown target → warning `Verbindung <p> -> <target>: Anschluss unbekannt`, not seated → `Verbindung <p> -> <target> sitzt nicht (<mm> mm)`. `transfer`: open port within 2 mm of the storey floor (`below`) / ceiling (`elevation + height`, `above`) or at / beyond the other face of the host wall (`beside`). `status` = `connected` | `open_ok` (listed in `open_ok`) | `transfer` | `open`.
- **Cable entry restrictions** (`PartPorts.cable_fits`): an entry port may carry `cable_types` (allowed `params.cable_type`), `cross_section` (mm²) and `label`; derived cable ends carry `cable_type` and `section`, a conduit carrying a cable carries the cable's `cable_type`/`section` on its ports (also in `installation.cables`). Errors → `{"error": <first>, "errors": [...]}`, nothing written. `create` and exists → `existiert bereits: <ref>`; update of a missing element → `unbekannt: <ref>`. No renaming.

**Editing openings**
- `storey` = storey id with a loaded file, `wall` = a wall id of it (else `unbekannt: …`); `opening` an object with `id` matching the id pattern; `OPENING_DELETE` needs an existing `id`. `create` and the id exists in the storey → `existiert bereits: <id>`; update of a missing id → `unbekannt: <id>`.

**Editing linings** (`LINING_SAVE`, `LINING_DELETE`)

**Editing walls** (`WALLS_SAVE`)
- `storey` must be a loaded storey; `upsert` walls are matched by `id` (new id → appended; ids must match the id pattern and be unique within the storey); every wall object is complete (`id, name?, assembly, start, end, reference, outside?, shape?, height?`); `openings` and `linings` of an existing wall are taken from the file (never from the request), a new wall starts without openings and linings. Lining `u0`/`u1` are shifted like the opening offsets (absolute position kept). `delete` removes walls (with their openings). `rooms.upsert` / `rooms.delete` likewise: a new room is taken as sent (without `coverings`); for an existing room the sent keys replace those of the file, all other keys and the `coverings` are kept (the plan editor sends `{id, name, polygon}`). `height` (number > 0) replaces the storey height.
- **Openings stay absolute:** for an updated wall whose direction is unchanged, every opening offset becomes `offset + (start_old − start_new) · d` (rounded to 0.0001); if the direction changed (rotation or reversal) the offsets are kept.
- **Moving openings between walls** (split, bay): an upsert wall may carry `take_openings: [ids]` – these openings are removed from the wall that has them in the file and added to this wall; their offset is recomputed from their absolute position (`offset = (P_old − start_new) · d_new`, `P_old` = `start_old + offset_old · d_old`) when the walls are parallel, else kept. `take_openings` is not stored.
- The changes are applied to a copy of the storey, the model is computed, and the **new errors** (not present before) are split: opening errors (`kind: "opening"`) are allowed and returned as `opening_conflicts: [{opening, wall, message}]`, lining errors (`kind: "lining"`) likewise as `lining_conflicts: [{lining, wall, message}]`, covering errors (`kind: "covering"`) as `covering_conflicts: [{covering, room, message}]`; any other new error → `{"error": <first>, "errors": [...]}` and nothing is written. Otherwise the storey file is written atomically (same writing rules) and the model invalidated.

**Editing rooms and shafts** (`ROOM_SAVE`, `ROOM_DELETE`, `SHAFT_SAVE`, `SHAFT_DELETE`, `RoomEditor`)

**Editing installed parts** (`PART_SAVE`, `PART_DELETE`, `PartEditor`)
- `PART_SAVE {upsert: [part], delete: [ids]}`: every part needs an `id` matching the id pattern (`ungültige Teil-id`); a deleted id must exist (`unbekannt: <id>`); an id twice or both upserted and deleted → `Teil doppelt in der Änderung`. An upserted id that exists is replaced, else created. Connections are made symmetric: a sent `connections` entry to an unknown part (or itself) is dropped, else the target port of a part outside the batch gets the back-link; afterwards every entry whose target is gone, or whose target in the batch does not link back, is removed (empty `connections` removed). The model is computed with the changed parts; **any** new error rejects the change (`{error, errors}`), else the changed part files are written / removed (`house/tga/parts/<id>.json`, same writing rules) and the model invalidated.
