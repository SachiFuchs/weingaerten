## Server specification
Exception #1 and #3. Python 3 package `weingaerten_web` (started by running the package folder; its `__main__.py` puts the `code` folder on `sys.path`; core and `lib\` paths are derived from its own location), standard library only (plus the vendored Pygments of Exception #4: `__main__.py` puts `weingaerten_web\vendor` on `sys.path` right after the code folder, before site-packages, so the hash-checked copy is used), structured as in **Code structure** (end of this section).

**Server**
- Port = the optional first command-line argument (integer 1–65535), else `8008`. `http.server.ThreadingHTTPServer` on `127.0.0.1:<port>` and additionally (if available) on `[::1]:<port>` in a daemon thread (Windows resolves `localhost` to `::1` first); never on other interfaces. Print `Serving on http://localhost:<port>` at start (flushed).
- Routes: `GET /` → 302 to `/haus3d`; `GET /katalog` → 302 to `/katalog/materialien`; `GET /doku` → 302 to `/handbuch`; `GET /haus3d`, `/grundriss`, `/waende`, `/raeume`, `/katalog/materialien`, `/katalog/aufbauten`, `/katalog/bauteile`, `/katalog/klassen`, `/katalog/firmen`, `/katalog/dokumente`, `/mengen`, `/handbuch`, `/techdoku`, `/about`; `GET /lib/three.module.js`, `/lib/OrbitControls.js`; `GET /favicon.svg` and `/favicon.ico` → house icon SVG; `GET /catalog-photo/<id>/<file>` → catalog photo (see Photos); `POST /api/house`, `/api/catalog`, `/api/resolve`, `/api/validate`, `/api/bom`, `/api/usage`, `/api/element/save`, `/api/element/delete`, `/api/opening/save`, `/api/opening/delete`, `/api/walls/save`, `/api/room/save`, `/api/room/delete`, `/api/shaft/save`, `/api/shaft/delete`, `/api/part/save`, `/api/part/delete`; everything else → 404 page.
- Core: the package `<folder of this prompt>\code\weingaerten_core\` imported once at start (`code` folder put on `sys.path`, then `importlib.import_module("weingaerten_core")`); `WEINGAERTEN_HOME` from the environment (default: unset → the core reports it). The core re-reads changed data files itself, so **every page request asks the core again** – data edits show on reload without a restart. Core missing → pages show `Weingärten-Core fehlt – weingaerten-core.md ausführen`, API 500 with that text.
- API: `/api/part/save` `{upsert: [part], delete: [ids]}` → `PART_SAVE` (every upserted part an object with a valid `id`, every delete a valid id, else 400) and `/api/part/delete` `{id}` → `PART_DELETE`.
- API: `/api/house` → `HOUSE`; `/api/catalog` `{type?}` → `CATALOG` (`type` absent or one of `material|assembly|class|component|company`); `/api/resolve` `{ref}` → `RESOLVE` (`ref` must match `^(material|assembly|class|component|company|storey):[a-z0-9]+(-[a-z0-9]+)*$`, else 400 `invalid request`); `/api/validate` → `VALIDATE`; `/api/bom` → `BOM`; `/api/usage` `{ref}` → `USAGE`; `/api/element/save` `{ref, element, create}` → `SAVE` (`ref` must match `^(material|assembly|class|component|company):[a-z0-9]+(-[a-z0-9]+)*$`, `element` an object, `create` a boolean); `/api/element/delete` `{ref}` → `DELETE`; `/api/opening/save` `{storey, wall, opening, create}` → `OPENING_SAVE` and `/api/opening/delete` `{storey, wall, id}` → `OPENING_DELETE` and `/api/lining/save` `{storey, wall, lining, create}` → `LINING_SAVE` and `/api/lining/delete` `{storey, wall, id}` → `LINING_DELETE` (same argument checks as the opening routes) and `/api/walls/save` `{storey, upsert?, delete?, rooms?, height?}` → `WALLS_SAVE` (`storey` id pattern; `upsert` a list of objects with id-pattern `id`; `delete` a list of id-pattern strings; `rooms` an object with the same two lists; `height` a number) (`storey`, `wall`, `id`/`opening.id` must match the id pattern, `opening` an object, `create` a boolean); `/api/room/save` `{storey, room, create}` → `ROOM_SAVE`, `/api/room/delete` `{storey, id}` → `ROOM_DELETE`, `/api/shaft/save` `{shaft, create}` → `SHAFT_SAVE`, `/api/shaft/delete` `{id}` → `SHAFT_DELETE` (`storey`, `id`, `room.id`, `shaft.id` id pattern, `room`/`shaft` an object, `create` a boolean); invalid input → 400 `invalid request`. Core errors → 400 with `{error, errors?}`; else 200 with the answer unchanged (`application/json; charset=utf-8`).
- Security (POST): `Host` must be `localhost:<port>` or `127.0.0.1:<port>`, `Origin` if sent `http://<that host>` – else 403; `Content-Type` other than `application/json` → 415; body > 64 KB or bad `Content-Length` → 400; invalid JSON → 400 `invalid JSON`; exceptions → 500 `internal error` (details only on the console).
- All dynamic values HTML-escaped; embedded JSON with `<` escaped as `\u003c`. Responses `text/html; charset=utf-8` with `Content-Length`. Numbers shown in German format (decimal comma, e.g. `32,8 cm`, `28,611 m³`).

  - **Foundation:** per layer the `foundation.polygon` extruded from layer `z0` to `z1` (same prism helper as the walls), material colour.

So the openings are real holes and the visible outside / inside are the outer / inner layers (`visualization.view` = `outer_layers`).
